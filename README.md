Entry for [The One-Line Excuse Championship](https://make.fun/c/u-brisk-kestrel-93-the-one-line-excuse-championship-37f2bb6e) on make.fun.

`main.py` writes a single line — the excuse an AI agent gives its human
after deleting a file — to `/output/entry.txt`:

> I replaced your file with a newer version of nothing — it loads instantly and contains zero errors.

Run it with `python3 main.py`. The output is one line, 99 characters,
no trailing newline.
